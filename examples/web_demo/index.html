Encrypt / Decrypt

One-off jobs for any file or folder on this computer, using the enrolled drive's key (AES-256-GCM). Drop things on a side, or pick them with the buttons. Auto runs as soon as you drop; Manual collects them until you press the button.

Dropped items: a browser never tells the page where a file lives, so the demo looks for it by name, size and date under Desktop, Downloads, Documents, Pictures, Videos, Music (and OneDrive). If it cannot be found, use the Files…/Folder… buttons, which open a normal Windows file dialog. Folders keep their structure; each file becomes name.ext.utenc.

Bound Folders

Folders that are always encrypted on disk. With the drive plugged in, double-click any .utenc file in Explorer: it is decrypted to a private working copy and opened in its usual program; every save is encrypted back over the .utenc. Pull the drive out and the working copy is deleted and nothing opens.

EVENT TRACE
[SYSTEM] Bind a folder, then register double-click to open.
Registration is per user (HKCU\Software\Classes\.utenc, no admin) and runs usbtether open "%1"; Remove undoes it. Binding only encrypts the folder's files: nothing is deleted except the plain originals, after the encrypted copy is written. While a file is open its plain copy sits in %APPDATA%\usbtether\open; if the helper is killed, the next open (or this page) syncs unsaved changes back and deletes it. Editors such as Notepad keep no lock, so "closed" cannot be seen: the copy goes when the drive is pulled out or after 30 minutes without a save. Auto mode needs this demo page's server running.
